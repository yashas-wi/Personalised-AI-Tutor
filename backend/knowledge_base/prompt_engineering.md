# Prompt Engineering and In-Context Learning

## Principles of Prompt Design
Prompt engineering involves crafting inputs to guide Large Language Models toward accurate, reproducible, and structured outputs without fine-tuning model weights.

## Key Prompting Techniques
1. Zero-Shot Prompting: Direct task description without examples.
2. Few-Shot In-Context Learning: Supplying demonstration pairs.
3. Chain-of-Thought (CoT): Instructing the model to think step-by-step.
4. Structured Output Enforcement: Prompting for JSON schemas or constrained outputs.
