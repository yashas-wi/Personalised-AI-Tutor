# Reinforcement Learning (RL)

## Core RL Framework (MDP)
Reinforcement Learning models decision-making through Markov Decision Processes (MDPs), defined by States, Actions, Transition Probabilities, Rewards, and Discount Factor.

## Q-Learning and Policy Gradients
1. Value-Based (Q-Learning / DQN): Learns the action-value function measuring the expected return.
2. Policy-Based (Policy Gradients / PPO): Directly parameterizes the policy and optimizes using gradient ascent.
