# LLM Architecture and Training Pipelines

## Pretraining, Alignment, and Fine-Tuning
1. Pretraining: Self-supervised learning on massive text corpora.
2. Instruction Fine-Tuning (SFT): Training base models on high-quality curated prompt-response pairs.
3. Reinforcement Learning from Human Feedback (RLHF): Aligning models to human preferences using Reward Models and PPO/DPO.

## Inference Optimization
Techniques such as KV-Caching, Quantization, and Speculative Decoding reduce latency during generation.
