# 🧠 AI Tutor — Personalised AI Tutor for Learning AI

> **Build Fast with AI: AI Build Challenge 2026** — Problem Statement: *Personalised AI Tutor for Learning AI*

An adaptive AI tutoring platform that creates personalized learning paths for mastering AI/ML concepts. It adjusts difficulty, explanations, and practice questions in real-time based on each learner's progress.

## ✨ Features

- **🎯 Adaptive Learning Paths** — Diagnostic assessment determines your level, then builds a custom curriculum
- **📚 AI-Generated Lessons** — RAG-powered explanations grounded in a curated AI/ML knowledge base
- **🧪 Smart Quiz System** — Mix of MCQ and open-answer questions with AI grading and feedback
- **💬 Chat with Your Tutor** — Streaming AI chat assistant with full context awareness
- **🚩 Human-in-the-Loop Review** — Flag any explanation to get an AI-generated alternative
- **🃏 Flashcard Review** — Spaced-repetition style review cards generated by AI
- **📊 Progress Dashboard** — Visual topic mastery tracking across 10 AI/ML domains

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js 14, React 18, TypeScript, Tailwind CSS, Framer Motion |
| Backend | Python 3.11, FastAPI, Uvicorn |
| AI Engine | Google Gemini 1.5 Pro (with Flash fallback) |
| RAG | ChromaDB + Google text-embedding-004 |
| Database | SQLite via SQLAlchemy |

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ and npm
- Python 3.11+
- Google AI Studio API Key: https://aistudio.google.com

### Backend Setup
```
cd backend
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
copy .env.example .env         # Then edit .env with your GOOGLE_API_KEY
uvicorn main:app --reload --port 8000
```

### Frontend Setup (new terminal)
```
cd frontend
npm install
npm run dev
```

Visit http://localhost:3000

## 🐳 Docker
```
docker-compose up --build
```
